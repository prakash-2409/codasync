# PROJECT CONTEXT: Sienna OS (Placement Dashboard)

## Objective
Build an independent, centralized MERN stack web application for St. Joseph's College of Engineering students to track and achieve placement eligibility criteria (Up to 5 LPA, 5-10 LPA, >10 LPA tiers).

## Core Philosophy: The Single-Threaded Recommendation Engine
Standard educational dashboards fail due to information overload. This platform acts as an **Active Peer-Motivated Routing System**. It calculates exactly what the student MUST do right now (e.g., LeetCode, CodeChef, Skillrack, NPTEL) to hit their specific placement tier and hides the rest. 

## Design System (Strict Constraints)
*   **Aesthetics:** High-end, editorial, distraction-free. 
*   **Color Palette:** Must exclusively use variations of **warm-brown, parchment, and sienna**. 
*   **Typography:** Clean sans-serif for UI elements, serif for long-form reading (if any).

## Target User Behavior
*   Reduce the friction of finding contest links to zero.
*   Push users to code daily using gamified "proof-of-work" heatmaps.
*   Isolate domains ("Focus Mode") so users aren't overwhelmed by context-switching between CP, web dev, and aptitude tests.
